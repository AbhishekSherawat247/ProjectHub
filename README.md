## Projects

### 1. Potato Leaf Disease Detection Using CNN

**Objective:** To classify potato leaf images into different disease categories using deep learning techniques.

**Technologies Used:**
- Python
- TensorFlow and Keras
- Convolutional Neural Networks (CNN)
- Google Colab
- NumPy, Pandas, Matplotlib, and Scikit-learn

**Project Notebook:** [View Potato Leaf Disease Detection](./PotatoLeafDisease%20%281%29.ipynb)

**Methodology:**
1. Dataset acquisition and exploration
2. Image preprocessing and resizing
3. Training, validation, and testing split
4. Data augmentation on training images
5. CNN model training and evaluation
6. Disease classification and performance analysis

**Evaluation Metrics:**
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
